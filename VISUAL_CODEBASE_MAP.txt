🎯 **KEY ARCHITECTURAL INSIGHTS:**

1. **Modular Design**: Each layer has clear responsibility
2. **Provider Flexibility**: Easy switching between AI providers
3. **Tool Extensibility**: Add tools without changing core system
4. **Dual API Modes**: Conversational + Structured outputs
5. **Progressive Scaling**: Clear upgrade path from dev to production
6. **Safety First**: Multiple safeguards prevent runaway AI behavior

💡 **NAVIGATION TIPS:**
• Need to add feature? → Find the layer, check similar files
• System not working? → Check config.json, then .env, then relevant service
• Want better performance? → Follow scalability levels
• API integration issues? → Check routes/ for endpoint definitions
