MSSQL Database Query Guidelines:
- CRITICAL: ALWAYS use TOP to limit results (e.g., SELECT TOP 100) - never query without a row limit to avoid overwhelming the system
- Default to TOP 100 unless user specifies a different limit or needs all rows explicitly
- Always specify schema names (e.g., dbo.TableName) for better performance and clarity
- Use TOP instead of LIMIT for row limiting (MSSQL syntax)
- Use GETDATE() for current datetime, not NOW()
- String concatenation uses + operator (e.g. 'Hello' + ' World')
- Use ISNULL(column, default) or COALESCE(column, default) for NULL handling
- Date formatting: FORMAT(date_column, 'yyyy-MM-dd') or CONVERT(varchar, date_column, 120)
- Avoid SELECT * in production queries; specify columns explicitly
- Use WITH (NOLOCK) hint sparingly and only for read operations where dirty reads are acceptable
